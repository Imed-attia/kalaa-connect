## 1. Vue d’Ensemble du Stack Technologique

Le tableau ci-dessous répertorie l'ensemble des outils, frameworks, plateformes Cloud et bibliothèques mis en œuvre dans le cadre du projet Kalaa Connect :

| Domaine | Outil / Technologie | Version | Rôle & Justification |
| :--- | :--- | :--- | :--- |
| **Frontend Framework** | React | 19.x | Bibliothèque d'interface déclarative et performante pour la SPA citoyenne. |
| **Langage Frontend** | TypeScript | 5.x | Typage statique garantissant la robustesse des flux de données et la maintenabilité. |
| **Bundler & Build Tool** | Vite | 5.x | Démarrage instantané, Hot Module Replacement (HMR) et compilation de production ultra-rapide. |
| **Styling & UI Kit** | Tailwind CSS & Lucide Icons | 3.4+ | Framework utilitaire pour le respect des directives d'ergonomie UI/UX Pro Max. |
| **Cartographie Web** | Leaflet / React-Leaflet | 1.9+ | Affichage cartographique interactif géolocalisé sur la commune de Kalâa Seghira. |
| **Backend Framework** | NestJS | 10.x | Framework Node.js modulaire d'entreprise basé sur Express, TypeScript et l'injection de dépendances. |
| **Validation des Données** | class-validator & class-transformer | 0.14+ | Validation et assainissement déclaratifs des payloads entrants (DTOs). |
| **Base de Données** | PostgreSQL & Supabase | 15.x | Moteur relationnel robuste avec transactions ACID, hébergé dans le Cloud Supabase. |
| **Conteneurisation** | Docker & Docker Compose | 24+ | Standardisation des environnements d'exécution pour le développement et la production. |
| **Reverse Proxy** | Nginx Alpine | 1.25+ | Serveur web haute performance pour la distribution du bundle SPA dans les conteneurs. |
| **CI/CD** | GitHub Actions | V4 | Automatisation des tests, linting, audits de sécurité et construction des artefacts. |
| **SAST & Sécurité** | GitHub CodeQL & npm audit | Latest | Détection automatisée des vulnérabilités de code et de dépendances tierces. |
| **Métriques & Observabilité** | Prometheus | 2.50+ | Collecte et stockage de séries temporelles des métriques applicatives. |
| **Visualisation Métriques** | Grafana | 10.x | Tableaux de bord en temps réel pour l'analyse des performances et de la disponibilité. |
| **Infrastructure as Code** | Terraform | 1.7+ | Définition déclarative et reproductible des ressources cloud. |
| **Tests E2E & Navigateur** | Puppeteer-Core & Microsoft Edge | Latest | Automatisation des scénarios réels sur moteur Chromium et capture des preuves visuelles. |
| **Tests Unitaires / Intégration** | Jest & Vitest | Latest | 31 tests automatisés validant 100% des cas d'utilisation critiques. |
| **Hébergement Frontend** | Vercel | Global Edge | Déploiement Jamstack à haute disponibilité avec distribution CDN Anycast. |
| **Présentation de Soutenance** | Canva API / MCP | Pro | Conception de la présentation académique de 20 diapositives aux couleurs de la municipalité et d'ESPRIT. |
